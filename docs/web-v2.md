# Web V2 在线播放与界面改版

参考 zfdang/hongguo-open-player，冻结提交567b490fd2606c134d2a5e50722b59e355a430ce。沿用其产品思路：内容优先目录、深色顶部导航、沉浸播放器与分组选集。未搬用其前端代码。

server/mp4-stream.cjs 提取并适配其 src/server/native/hongguo.js 的MP4解析、CENC容器重写和分片计划；server/range-media.cjs 来自其 services/rangeMedia.js，移除日志并接入本项目官方CDN与公网DNS保护。保留各源文件GPL-3.0-only标识；参考仓库根AGPL-3.0文本另存server/licenses/LICENSE.open-player.txt。Web页脚提供本站完整对应源码包（排除凭据、缓存、用户数据和node_modules）。原项目LICENSE、NOTICE和第三方声明保留。

原生App播放签名沿用本项目自己的实现；新增仅Web协议选项：当前player/v1 POST、gzip正文dr_scene、安装身份纳入Argus、签名stub大写及匿名install_id Cookie。原桌面默认协议未改。Web下载同样走已验证的新协议。

按需在线播放：认证POST /api/play只接受属于真实目录的分集，建立有界MP4元数据计划，返回不含上游地址和密钥的不透明路径。媒体请求按当前会话校验，可任意有效Range拖动；读取CDN块后按AES-CTR偏移解密，改写moov为可播放容器。每个页面仅保留一个播放计划；过期、注销或主动退出后释放。断开的请求通过AbortSignal停止远端读取；无业务轮询。

浏览器不支持HEVC或片源为ByteVC2时转兼容下载队列，SSE更新进度。用户手动切兼容模式可重建H.264/AAC。ByteVC2组件来自上述参考仓库v1.12.1官方arm64发行包，本机配置指向.web-runtime/bin/ffmpeg-bytevc2，组件归原许可证和来源，不将普通FFmpeg冒充ByteVC2解码器。

候选运行目录与旧版运行数据分离。最终仍更新原公网https://hongguo.paws.rodeo/，访问令牌和追剧/观看记录存储键保持。

## 候选验收

- 23项Web/后端协议检查、94项原生播放签名/回退/取消/节奏检查通过，共117项。git diff --check通过；设计探测器P0为0，倍速选项被误判为精确数字的提示不适用。
- 真实素材来自原目录随机选择的《贪恋她》77集。本轮第一集完整源1080×1920、100.1秒，按需解密元数据计划164ms（不含注册/模型获取）；完整解密成品ffprobe识别HEVC/AAC。
- Ego中首集静音实际播放；拖至70秒继续播放；手动下一集到第二集（174.57秒），第二集接近结束后实际ended事件自动进入第三集并播放。
- 第三集切兼容模式，H.264/AAC成品73.63秒、1080×1920；静音实播及拖至41秒通过。退出后观看记录继续第三集，42秒以上恢复通过。
- 320/375/414/768px宽度检查：无横向溢出，导航/搜索在视口内，手机导航点击高度44px。关键目录、真实播放和手机状态已报告Happy Skills。
- 发现并修复：匿名注册profile与播放请求版本不一致、旧接口及签名遗漏安装身份；同一进程重注册引发的空响应；下载任务缺vid导致兼容续播回到首集。现代身份只在本机ignored运行目录保存自己的匿名设备，不导入参考仓库的静态共享设备。
- ByteVC2组件来自v1.12.1官方arm64ZIP，ZIP与上游SHA256SUMS一致；二进制decoder列表包含bvc2。当前选定真实素材返回HEVC，尚未以真实ByteVC2源实播，不把组件检查当ByteVC2完整验收。
