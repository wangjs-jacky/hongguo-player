## 页面结构

- 顶部品牌、频道导航、搜索、主题、历史与服务入口；手机使用独立底栏，44px触控。
- 首页精选大图与右侧发现列表；分类快捷入口、继续观看、热门/真人/漫剧/AI四个真实内容模块，共48张卡片。精选的简介和标签异步取得，先显示真实剧名和封面。
- 分类片库保留题材筛选与真实分页；排行榜保持来源顺序；收藏、历史及下载保留。
- 剧集和演员由模态窗改为独立页面：海报、简介、评分、主演、作品、季和分集。
- 播放改为常规页面，保留顶部导航；视频加右侧选集，手机上下排布。支持正常返回、地址栏深链、连接后恢复深链、主题切换。
- 播放、解密、兼容转换、弹幕、续播、预载和SSE继续复用原业务。没有把演示数据代替真实接口。

## 性能与交互修复

V3测量及功能矩阵归docs/web-v3.md。本轮进一步修复快速搜索时短暂显示旧卡片、可能误点旧剧集的问题；新请求显示占位，旧响应不能覆盖新查询。

现代Web注册和播放模型改为受公网地址检查的直接请求，不修改全局代理或桌面默认协议。新请求实测1441ms；改变画质可复用45秒内已取得且满足尺寸要求的真实rendition，避免重复解析模型；源复用样本0ms。切画质仍需媒体头与客户端准备，不承诺总切换耗时为0。

浏览器实测暂停于31秒切1080P后仍暂停且恢复31秒；实际画质1080×1920，完整时长100.100998秒。预载与缓存均有界，由用户/视频事件触发，没有业务轮询。旧live-check状态轮询已改SSE。
