2026-11-23。按用户提供的 `hongguo-v1.2.31-macos-universal.zip` 和 `morluto/rea` 分析结果，把红果桌面 App 的整体信息架构移植到现有 Web。正式站入口和端口不变，静态版本由 4.2 升为 5.0。

> 2026-11-23：V6 已改为直接复用原版 App 前端，并替换正式发布目录；本文保留为 V5 结构移植记录。

## 逆向证据

- 安装包已解压到 `~/Downloads/hongguo-re/`；App 为 `短剧播放器.app`，bundle id `com.wails.hgplayer`，版本 `1.2.31`，universal 二进制。
- REA 报告：`rea-js-summary.json`、`rea-go.json`、`rea-desktop.json`；JS 摘要覆盖 532 个已检查项，完整证据为 `evidence-js.json`。
- Go 构建信息：`go1.25.0`，入口模块 `hg-go/cmd/hgplayer`，使用 Wails 2.11 与 WKWebView；前端资源包含 Vue 3.5.43、xgplayer 和 HEVC WASM。
- App 在本机启动后为白屏，说明 Wails/WKWebView 静态资源加载异常。因此本轮确认的是可提取的静态前端结构、路由语义和依赖事实；Go 业务逻辑、媒体协议与运行时行为没有全部还原，不能声称完整 App 克隆。
- 分析只用于结构与交互参考。Web 继续使用本项目自己的 HTML/CSS/JS、真实红果接口和现有播放链路，没有复制 App 图片、商标或打包资源。

## 结构映射

| App 结构 | Web 5 路由 | 数据与行为 |
|---|---|---|
| 推荐/首页 | `#/recommend` | 热门精选、四类真实片单、继续观看和分类快捷入口 |
| 排行 | `#/rank`、`#/rankings` | `/api/catalog` 的榜单分类，保序展示，不伪造热度 |
| 新剧 | `#/new` | 近期片单分类，按上游列表顺序展示 |
| 搜索 | `#/search?q=` | 真实搜索、分页与最近搜索 |
| 剧星榜/演员 | `#/actors`、`#/actor/:id`、`#/user/:id` | 演员榜、演员详情和作品；作品接口允许公开读取 |
| 收藏/历史/点赞 | `#/favorites`、`#/history`、`#/likes` | 保存在当前浏览器，刷新后保留 |
| 我的 | `#/mine` | 本地观看空间和收藏/历史/点赞计数 |
| 详情 | `#/series/:id` | 海报、简介、主演、季、分集和本地点赞/追剧 |
| 播放 | `#/play/:series/:vid` | 真实流式播放器、选集、下载、兼容播放、SSE 任务 |
| 下载管理/设置 | `#/tasks`、`#/settings` | 本人管理权限、任务事件和播放偏好 |

兼容旧地址 `#/watch/:series/:vid`。桌面使用固定侧栏，移动端使用底部导航和抽屉；默认深色主题，侧栏可折叠。

## 实现范围

- 推荐页从四个真实分类各取 12 部，共 48 张卡片；演员、排行榜、新剧、搜索均调用现有真实接口，不使用演示数据。
- 详情页保留真实分集数量、演员关系和本机追剧/点赞；播放页继续复用原有的取源、解密、Range 流、兼容转换、弹幕、续播、预载和 SSE。
- 统一了顶栏与侧栏的任务计数和连接状态；修复主滚动容器和深链恢复；公开访客可读取演员作品。
- 正式静态文件仍在 `server/public/`，开发副本在 `server/web-v5/`。切换前旧版备份在 `.web-runtime/public-before-v5-20261123/`。

## 限制与后续

- App 的预约、消息、账号等依赖原生客户端的模块没有对应本地后端，未伪造实现；如需这些页面，应先补真实数据源。
- App 白屏使 Go 运行时行为仍属未完全还原；上架或像素级复刻前应继续做静态资源、协议和交互对照。
- 上游短剧取源会间歇返回 HTTP 200 空正文；同一时间候选与正式站均可能失败，不能由详情目录成功推导每集可播。
- 本轮没有提交、推送或发布 Release；正式站只是本机 `3188` 进程切换到 V5 静态资源。
