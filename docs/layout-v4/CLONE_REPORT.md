参考站采用其真实部署资源作结构依据，未假称可正常访问受限的线上首页。红果页面使用自己的实现与片源。

| 验收项 | 结果与范围 |
|---|---|
| 首页结构 | 已接入精选+侧列、快捷入口、继续观看和四个真实频道 |
| 内容完整 | 候选48张卡片；完整简介、14位主演、77集；演员20部作品 |
| 导航与返回 | 独立详情、演员、播放地址；浏览器返回和连接后恢复深链通过 |
| 媒体能力 | 候选真实流式与兼容H.264/AAC播放、暂停切画质保留31秒；公网实播通过 |
| 响应式 | 320/375/768/1440视口验证；手机底栏44px；非实体手机验收 |
| 外观 | 浅/深主题与精选切换通过；内容替换保留红果品牌；用户审美反馈待收 |
| 来源审计 | 未发布原站JS/CSS、动漫图片、广告、登录或媒体API；本地参考副本独立 |
